This project taught me that Streamlit reruns the entire script on every interaction, so persistent data like my action history list must be stored in st.session_state. I also saw how quickly buttons and st.metric can create a clean, professional interface. I still find it challenging to trace control flow through nested if statements in one large function and to predict how the history list re-renders on each rerun. My parsing logic in process_files worked but failed the tests because I hadn't checked the expected output format. Next time, I will read the test file before coding and sketch the rerun flow and session_state keys on paper. I will also split my logic into smaller helper functions for parsing, state updates, and display.
