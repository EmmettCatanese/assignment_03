This project taught me that Streamlit reruns the entire script on every widget interaction, so data that needs to persist, like my action history list, must be stored in st.session_state. I also enjoyed how quickly features like buttons and st.metric produced a clean, professional interface. My biggest challenges were tracing control flow through nested if statements in one large function and adjusting to re-rendering the full history list on each rerun. I also found that my parsing logic in process_files worked but failed the tests because I hadn't checked the expected output format. Next time, I will read the test file before coding, sketch the rerun flow and session_state keys on paper, and split my logic into smaller helper functions for parsing, state updates, and display.
